# Illustration du professeur Squoinks

Asset final : `public/images/professeur-squoinks.png`.

Méthode : génération avec l’outil intégré ImageGen, puis copie dans les assets du projet. Fond transparent, image inspectée visuellement. Le personnage est original et sert d’habillage discret aux cours. Les figures techniques sont du SVG produit par le code de l’application, pour garder textes et schémas précis.

Prompt final utilisé :

Create one original friendly scientist character, a waist-up cartoon portrait, with exuberant spiky light-blue hair and a prominent tidy dark blue moustache, wearing a white laboratory coat over a sage green sweater. Expressive kind eyes, slightly amused wise expression, one hand holding a small waveform sketch on a plain small notepad, other hand relaxed. Clean hand-drawn editorial illustration, confident dark forest-green ink outlines, subtle paper texture inside the colored shapes, muted sage/cream palette with blue hair accent. Clear expressive silhouette suitable for display at 180px. Centered, square composition with some breathing room, all hair and hands inside frame. Transparent background. No lettering, no speech bubbles, no logos, no watermark. This is an original educational professor mascot, not an exact existing television character.
